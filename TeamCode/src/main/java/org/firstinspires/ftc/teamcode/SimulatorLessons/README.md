# FTC Simulator Lessons

Choose a challenge, test an idea, and teach the team something you learned.

## Start here after stand-up

1. Open [FTC Sim](https://ftcsim.org/) and use your coach-assigned login. Ask Coach if you need access; do not share passwords in your notes.
2. New to the simulator? Start with **FTC Intro** and its built-in Blocks tutorial. Already started? Reopen your saved work, explain where you left off, and pick your next unfinished challenge.
3. Choose [Movement](FtcMovement/readme.md) to practice routes and turns, or [Sensors](FtcSensors/readme.md) when you can explain basic movement and want the robot to make decisions.
4. Pick one small goal: “I will make / test / explain ___.” Keep a record of your prediction, change, result, and next step.
5. Save time for the team share-out. Everyone will show their own progress and answer questions about the blocks or Java they used.

## Blocks and Java are two ways to express your instructions

Use the built-in tutorial in Blocks, then save a copy and use **OnBot Java** to see the translation. Match two blocks to their Java lines and explain what they do. Save Java edits before converting Blocks again, because conversion can overwrite them.

Android Studio is optional for tonight's simulator work. Each local lesson guide includes a full starter file, the correct package and class name, and instructions for copying it back to the simulator. The simulator copy uses the class name **MyFIRSTJavaOpMode** and no package declaration.

## Expectations for our programming team

Everyone contributes, learns, and shares. Choose a level that challenges you and keep working on a clear next step. When sharing a computer, rotate who types every 5–7 minutes; both people explain their own contribution. If stuck, show what you expected, what happened, and what you tried.

Coach's solutions are available to study. You may use them, but be ready to identify what you borrowed, explain it, and predict or demonstrate a change. You can share a useful failed experiment or an unfinished solution; your explanation and next step matter.
