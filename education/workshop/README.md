# Tank-drive workshop

Read the [walkthrough](tank-drive-coding-walkthrough.html), with the [Java primer](../java-primer/java_primer.html) as a reference.

In Android Studio, open `org.firstinspires.ftc.teamcode.education.workshop.tankdrive` in TeamCode:

- [Starter](../../TeamCode/src/main/java/org/firstinspires/ftc/teamcode/education/workshop/tankdrive/TankDrive_Tutorial_Start.java)
- [Completed example](../../TeamCode/src/main/java/org/firstinspires/ftc/teamcode/education/workshop/tankdrive/TankDrive_Complete.java)

Both examples are disabled by default. Remove `@Disabled` from your working copy for a supervised workshop and restore it afterward. The completed example expects four motors named `FL`, `FR`, `RL`, and `RR`; these are the workshop hardware names, not the competition robot configuration.

Supporting material: [components diagram](ComponentsDiagram.png) and the original [draft PDF walkthrough](code-tank-drive-walkthrough-draft.pdf). The PDF has no Java package or file-path references and is preserved unchanged. The HTML guide's missing logo reference was removed; its authored layout and teaching content are retained.
